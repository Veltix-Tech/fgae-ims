## How to read the columns

- **Default "none (generated by Prisma)"** means the database has no default: the backend creates the UUID. Raw SQL inserts must supply `id` (use `gen_random_uuid()`).
- **Default "none (set by Prisma)"** is the same for `updatedAt`: raw SQL inserts must supply it (use `now()`).
- **ON DELETE RESTRICT** means a row cannot be deleted while others point to it, so history stays intact. CASCADE deletes the dependent rows too. SET NULL clears the link.
